Источник: `test.csv`, 262144 строк. ClickHouse 25.8.33.6.

Kafka подтвердила 262144 сообщений. В обеих таблицах по 262144 строк без повторяющихся row_id. Все поля каждой строки сверены с CSV. Результаты SQL до и после оптимизации совпали с независимым расчетом в Python. В итоговом файле 51 строк, по одной на каждое значение us_state, включая DC.

## Замеры

По 7 измерений каждого варианта после прогрева. Порядок запуска чередуется, query cache выключен, max_threads=2. Перед замером обе таблицы приведены к одной части через OPTIMIZE FINAL. Это отдельный шаг эксперимента, а не настройка фоновой загрузки.

| optimized_without_projection | 25 | 27.33 | 262144 | 4.71859e+06 |
| optimized | 1 | 2.537 | 51 | 8729 |

Отношение медиан времени base / optimized: 28.00. Это результат этого запуска, не гарантия для другого компьютера.

Использование проекции by_state проверено по system.query_log. Исходные измерения находятся в benchmark.csv. Время со стороны клиента включает HTTP, серверное время берется из query_duration_ms. Замер выполнен на прогретых данных, это не тест холодного диска.
